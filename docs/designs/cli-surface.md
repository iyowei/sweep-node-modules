## 命令面 (v1)

```text
sweep-nm                    预览: 清单 + 体积 + 合计, 零副作用
sweep-nm --yes              执行删除
sweep-nm --exclude <名字>   临时追加排除, 可重复
sweep-nm --include <名字>   只清理命中名单的目录, 可重复
sweep-nm --config <路径>    指定配置文件 (优先于 SWEEP_NM_CONFIG)
sweep-nm init               初始化向导: 交互式生成配置文件
sweep-nm --help             帮助
```

- 项目名 `sweep-node-modules`, 命令名取短变体 `sweep-nm` (仿 `flatten-folder-cli` → `flatten-folder` 的旧例)。
- **主命令 + 子命令形态**: 缺省 `sweep-nm` 即清理流程 (预览; 加 `--yes` 执行); `init` 为子命令, 承载初始化向导。子命令位只为工具自身的辅助动作保留, 不承载其他清理能力 (模拟器等另立兄弟项目)。
- 判定模型与执行模型见 [ADR 0002](../adrs/0002-fixed-config-and-preview-execution.md); 初始化向导的交互见 [配置与初始化](config-and-initialization.md)。

## 退出码

| 码  | 含义                                                                                           |
| --- | ---------------------------------------------------------------------------------------------- |
| 0   | 成功 (含预览、空结果)                                                                          |
| 1   | 任一失败 (删除失败 / 整批中止 / 未处理目标 / 配置损坏或不存在 / 参数错误 / 无配置下的执行拒绝) |

## 输出规格 (视觉规范: 紧凑式 + 色块)

设计语言: 少线多色块、紧凑排版, 零依赖手写 ANSI。示意:

```text
▍ SWEEP-NM  预览 · 2 个根: ~/dev · ~/lab
  █ 4.6 GB  acme-web         ~/dev/acme-web
  ▓ 1.6 GB  data-pipeline    ~/dev/data-pipeline
  ▒ 366 MB  docs-site        ~/lab/docs-site
  █ 合计 3 处 · 6.5 GB   加 --yes 执行删除
```

- 顶栏: 反色色块 + 模式 (预览 / 执行) + 根数 + 运行时自述; 根数 ≤ 3 时直接列出根路径 (家目录缩写); 运行时自述形如 `bun 1.4.2` (取运行时自报字段, 直接跑与经启动器跑都报真身), 仅真终端展示 (非 TTY 不增噪音);
- 顶栏下方的中性提示行 (`░`, 仅真终端): 名单生效回执等本次运行的说明; 走 stdout, 与清单共用视觉语言, 不打断顶栏与清单的紧邻关系 (名单写错的告警仍走 stderr 并保持在顶栏之前, 位置本身即是强调);
- 清单按体积降序; 每行: 体积档位色块 (大 ≥ 1 GiB / 中 ≥ 100 MiB / 小) + 右对齐体积 + 项目名 (亮) + 路径 (暗, 剥 `node_modules` 后缀并按显示宽度对齐, CJK 双宽);
- 测不到体积的目标保留在清单中作**占位行** (`?` + 中性色块 + 行尾注「体积统计失败: <原因>」), 不计入合计; 执行时计入失败;
- 名字含控制字符 / 需折叠空白时, 显示名经净化并在行尾标注「名字已净化显示」;
- 末行合计色块 (处数 + 总量), 预览模式附 `--yes` 提示;
- 执行模式: 逐行结果色块 (`✓` / `✗` + 失败原因), 汇总行含**释放体积** (`汇总 成功 N 处 · 释放 X · 失败 M 处`); 整批中止时逐行标注「整批中止, 未执行删除」并给出理由与未执行处数;
- 错误与告警走 stderr (TTY 下带红色 `✗` 前缀), 不污染 stdout 清单流;
- 降级: 非 TTY / `NO_COLOR` / 终端能力不足 → 纯文本 (空格对齐, 零 ANSI), 信息零丢失 (见 [ADR 0007](../adrs/0007-platform-portability.md))。
