## 校验不变量

任一删除目标必须同时满足, 否则整批拒绝 (保守优先):

1. 路径末段恰为 `node_modules` (对原始输入与 realpath 两者都判);
2. realpath 之后位于某个 `roots` 之下 (以 path.relative 语义判定, 禁字符串前缀比较; win32 按大小写不敏感);
3. 不是 `/` 本身, 也不是 home 本体;
4. realpath 去重后无重复目标。

## 执行语义

- 删除动作只在 `--yes` 下发生 (预览默认, 见 [命令面与输出](cli-surface.md));
- **组件级安全复核** (TOCTOU 防线): 每条删除前, 自 roots 至 target 父目录逐级 `lstat`, 任一组件为符号链接或非目录 → **整批中止** (剩余条目一条不删); roots 与 target 须同源拼写 (调用方须先 realpath 化 roots);
- **ENOENT 阶段两分**: 复核阶段组件 ENOENT → `failed` (组件消失 ≠ 目标消失, 可能被搬走仍在占盘, **不得报成功**; 文案含「请复查目标是否仍存在; 未执行删除」); rm 阶段 ENOENT (链路已全验为真目录) 才归 `missing` (成功侧);
- 逐条 `fs.rm(recursive)`, 单条 rm 失败不中断整批;
- 符号链接作删除目标: `fs.rm` 取 lstat 语义, 只删链接本身, 不跟随;
- 全部完成后打印结果汇总; 存在失败或整批中止即退出码 1 (中止另给「未执行删除 N 处」)。

## 残余风险 (安全复核的定量边界)

- **复核 lstat 与 rm 解析之间的窗口**: 实测 δ < 1.4µs, 攻击者最小操作周期约 195µs (相差两个数量级); syscall 级振荡攻击 322 次机会零越界 — **现实不可达, 可接受登记** (fd 级 openat / O_NOFOLLOW 是唯一终解, 运行时未暴露);
- **同型真实目录换位**: lstat 层不可识别 (换位后对象仍在 root 内且名为 node_modules); 其「假成功」危害面已由 ENOENT 阶段两分消除;
- **持续振荡可低成本触发整批中止** (约 4% 概率, fail-safe 方向): 无数据损失, 登记为已知 DoS 面。

## 错误与边界

| 场景                         | 处置                                                                                                                 |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 删除失败 (rm 已尝试)         | 逐条报错 + 「内容可能已被部分或全部删除, 请复查」, 末尾汇总, 退出码 1                                                |
| 复核未完成 (组件被替换)      | 整批中止, 未删除条目注明「未执行删除」, 退出码 1                                                                     |
| 复核未完成 (组件消失 ENOENT) | 该条 `failed` + 「请复查目标是否仍存在; 未执行删除」(并附「若目标确已不存在, 可忽略此条」), 不牵连其余条目, 退出码 1 |
| 目标已消失 (rm 阶段 ENOENT)  | 归 `missing`, 视为成功侧                                                                                             |
