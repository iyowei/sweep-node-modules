# 删除安全闸

> **状态**: 已定稿 (Accepted)
> **日期**: 2026-09-23
> **决策者**: 沈委
> **父文档**: [设计总纲](sweep-node-modules-design.md)

## 校验不变量

任一删除目标必须同时满足, 否则整批拒绝 (保守优先):

1. 路径末段恰为 `node_modules`;
2. realpath 之后位于某个 `roots` 之下;
3. 不是 `/` 本身, 也不是 `$HOME` 本体;
4. realpath 去重后无重复目标。

## 执行语义

- 删除动作只在 `--yes` 下发生 (预览默认, 见 [命令面与输出](cli-surface.md));
- 逐条 `fs.rm(recursive)`, 单条失败不中断整批;
- 全部完成后打印失败清单并置退出码 1。

## 错误与边界

| 场景     | 处置                         |
| -------- | ---------------------------- |
| 删除失败 | 逐条报错, 末尾汇总, 退出码 1 |
