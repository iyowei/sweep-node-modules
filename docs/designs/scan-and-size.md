## 扫描算法

1. 自每个根递归遍历; 目录名恰为 `node_modules` 时记录其父目录为「项目」, 并**不再下钻** (嵌套天然解决);
2. 符号链接目录不跟进 (防环、防误出根);
3. 排除判定在进入目录时进行: 路径段命中 `exclude` 即整棵子树跳过;
4. 多根结果合并, 按 realpath 去重;
5. 跳过 `.git` 目录 (不可能含项目依赖, 直接减掉整棵子树的遍历开销);
6. 根预检按错误码分流病因 (不存在 / 不可读 (权限不足) / 不是目录 / 其余带码), 单根失效不中断其余根;
7. 根与命中目标的去重键按平台风味归一 (win32 大小写折叠, 与安全闸同源);
8. 根自身名为 `node_modules` 不记录 (根 = 容器语义);
9. 根自身为符号链接 → 照常扫描 (显式即授权), realpath 去重防重复;
10. 两份名单各产出命中统计 (`excludeMatches` / `includeMatches`, 未命中的名称也在列): 破坏性动作的「保命名单」反馈通道, 名字打错不得静默 (白名单写错的后果更重: 筛选结果直接为空)。
11. 包含判定 (白名单) 与排除同款口径: 从根到 `node_modules` 的任意一级目录名命中 `include` 才纳入, 空数组不过滤; 同一级同时命中两份名单时**排除优先** (先按白名单筛出候选, 再从候选里排掉命中排除的)。**命中计数独立于排除优先**: 名字命中白名单即计入 `includeMatches`, 随后被排除截走仍计入 (截走不等于没匹配上), 免得被截走的名字以零命中报成「未匹配」, 诱导排查不存在的拼写问题。

**实现裁定 (基准 r1-r4)**: 三候选 (手写剪枝 / 原生 `recursive` 后过滤 / 有界并发) 同过契约与鲁棒套件后由基准裁定, 取**有界并发** (CONCURRENCY=32): 真实工作区 3.4s → 0.67s (4.8×); 并发上限经拐点扫描裁定 (先行广档扫描 8/16/32/64/128/256, 空载细扫 4/8/16/32/64), 取 32 (平台区起点, 256 起 median 回退)。原生 `recursive` 因「跟进符号链接 + 首个不可读目录中断整次调用」与契约硬冲突被实测弃用。

## 体积统计 (已裁定: 策略 A 双轨)

- **口径**: du 快路径 = 磁盘占用 (macOS / Linux, 与 Finder 一致); 纯实现基线 = 逻辑字节 (无 du 平台, 与 Explorer「大小」列一致): 各自对齐所在平台的原生惯例;
- **快路径**: unix 平台存在 `du` 时, 汇总全部命中路径后**批量单次** spawn (`du -sk -- <paths...>`, `--` 终止符防根名以 `-` 开头被当选项);
- **基线**: 无 du 平台走纯 JS 递归统计; 门面 (`size.ts`) 按 `findDu()` 探针二选一;
- 结果三桶: `entries` (可测量) / `unmeasured` (存在但测不到, 如权限; **不得静默移出清单**: 下游按占位行呈现并计入失败) / `warnings` (非致命, 如子目录降级); 「不存在」的路径仅告警、不入任何桶;
- **解析防御**: du 输出按行解析后做**多重集一致性校验** (解析出的路径须与输入一一对应), 不符即整体降级 `unmeasured`; 含 `\n` / `\r` 的目标在进命令行前即被拒 (防输出行注入);
- 统计不得跟随符号链接 (与扫描同策); 不得逐处 spawn 或逐处独立遍历。

## 性能要点 (热路径 = 目录遍历, 性能不能差)

- `readdir withFileTypes` 取条目类型, 免逐个 `lstat`;
- 命中 `node_modules` 即剪枝, 不下钻;
- 跳过 `.git` 目录; 符号链接目录不跟进;
- 遍历走**有界并发协作池** (显式栈 + 在飞计数, 无递归; 瓶颈是 readdir 往返延迟约 98µs/目录, 目标是填满 I/O 队列而非堆并行);
- 体积统计批量或单遍完成, 不逐处 spawn。

## 错误与边界

| 场景                               | 处置                                                                          |
| ---------------------------------- | ----------------------------------------------------------------------------- |
| 目录不可读                         | 告警并跳过, 不中断                                                            |
| 某根不存在 / 不可读 / 不是目录     | 按病因分流文案, 跳过该根                                                      |
| 存在但测不到体积                   | 归 `unmeasured`, 下游占位呈现并计入失败 (退出码 1)                            |
| du 输出不可解析 (如路径含控制字符) | 该目标归 `unmeasured`, 不进入删除批次                                         |
| 深链超 `PATH_MAX`                  | `realpath` 退化为字面路径 (两候选对称); 去重语义降级为字面拼写同一 — 已知边界 |
