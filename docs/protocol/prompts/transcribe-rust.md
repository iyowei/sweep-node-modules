## 二、行为面特化对照表 (逐条回答并实施, 不得留空)

| 行为面         | 参考实现的既定行为                                           | Rust 落点与陷阱                                                                                      |
| -------------- | ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| stdout 字节级  | 逐行打印, 非 TTY 零 ANSI, 行尾 `\n`, 无多余空行              | stdout 在非 TTY 下是块缓冲: 进程结束前必须显式 flush; 待定: {{STDOUT_STRATEGY}}                      |
| 退出码         | 成功 0; 参数错误 / 配置损坏 / 删除失败 1                     | `main() -> ExitCode` 或 `process::exit`; panic 不得落入正常路径; 待定: {{EXIT_STRATEGY}}             |
| stderr 形态    | 诊断行分级前缀 (告警 / 提示), 与 stdout 分离                 | 独立 `eprintln!`; 与 stdout 的交错顺序不做契约 (但同一流内顺序须稳)                                  |
| 错误语义       | 含错误码与人话中文的固定串 (逐字)                            | 手写 enum + `Display` (无 thiserror); 文案逐字对齐契约, 待定: {{ERROR_TYPE_STRATEGY}}                |
| 路径与符号链接 | lstat 语义 (符号链接不跟进); 目录条目类型判定                | `symlink_metadata` (不跟进) vs `metadata`; `read_dir` 条目无类型字段, `file_type()` 的调用与错误处理 |
| readdir 顺序   | 无顺序契约 (结果在结尾统一排序)                              | 不依赖 `read_dir` 顺序 (平台不定); 一切顺序敏感处显式排序                                            |
| 体积快路径     | 探测 `/usr/bin/du` 与 `/bin/du`, 批量单次 `du -sk`, 解析输出 | `Command` 捕获 stdout; 路径非 UTF-8 与解析边界, 待定: {{DU_PARSE_STRATEGY}}                          |
| 并发遍历       | 有界并发 (上限 32), 结果确定 (结尾排序 + realpath 去重)      | std 无 rayon: `std::thread` + channel, 或先串行保等价 (性能优化后置, 且不得改变输出)                 |
| 平台分支       | du 快路径仅 unix; win32 路径判定先大小写折叠                 | `#[cfg(unix)]` / `#[cfg(windows)]`; 折叠必须显式 `to_lowercase`, 不赖路径库内部行为                  |
| 字符串与编码   | 输出 UTF-8; 路径可能非 UTF-8 (unix 字节路径)                 | 展示与比较的降级裁决, 待定: {{NON_UTF8_PATH_POLICY}}                                                 |
| 环境变量读取   | 三级覆盖 (旗标 > 环境变量 > 平台默认)                        | `env::var_os` 与 `var` 的差异 (非 UTF-8 值); 空值与缺省语义逐字对齐契约                              |
| 文件系统效果   | 删除用递归删除且不跟进符号链接                               | `remove_dir_all` 的符号链接语义与参考实现逐条核对 (黑盒面用 fs 断言钉死)                             |
